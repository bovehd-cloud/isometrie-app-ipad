# Isometrie-App – GitHub-Pages-Upload

Dieser Ordner enthält ausschließlich die veröffentlichungsfähige Web-App.
Für GitHub Pages den gesamten Inhalt dieses Ordners in das Repository hochladen.

Die Zeichnungen, Projekte und die Auswahlwerte werden weiterhin nur lokal im Browser des jeweiligen Geräts gespeichert. Sie werden nicht an GitHub übertragen.
